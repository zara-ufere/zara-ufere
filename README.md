# Hi, I'm Zara!

I'm a computer science graduate from The College of New Jersey, based in Washington, D.C. I like building backend tools that check things: who has access to what, what an attacker did in a log, and whether a result in a dataset can be trusted.

I'm looking for roles in software engineering, IT support, and security or technology risk.

## What I've been building

- **[AccessGuard](https://github.com/zara-ufere/accessguard)**: an access governance service that finds separation of duties conflicts, refuses risky role grants, and keeps a tamper-evident audit log. FastAPI, SQLAlchemy, PostgreSQL.
- **[logsentry](https://github.com/zara-ufere/logsentry)**: reads web server and SSH logs, detects attacks, groups them into incidents, and scores itself against labelled attacks. Python and SQLite.
- **[cabi-analysis](https://github.com/zara-ufere/cabi-analysis)**: a SQL and pandas analysis of 6.4 million Capital Bikeshare trips, with tested cleaning rules and honest limits.
- **[astlogic](https://github.com/zara-ufere/astlogic)**: checks the structure of Python programs with Prolog rubrics, without running the code. It comes with my [research paper](https://github.com/zara-ufere/astlogic/blob/main/docs/paper.pdf).
